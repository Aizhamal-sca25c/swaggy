# Portfolio — Aizhamal

## Как запустить
1. Распакуй ZIP.
2. Открой `index.html` в браузере (двойной клик). Сервер не нужен.
3. Для проверки телефонной версии: F12 → значок телефона (Device Toolbar).

## Структура
- `index.html` — разметка (header, nav, main, section, footer)
- `css/style.css` — стили, цвета в переменных `:root`
- `js/script.js` — JavaScript
- `images/` — картинки и иконки

## JS-функции
1. Переключение светлой/тёмной темы (с сохранением выбора в localStorage)
2. Мобильное меню (бургер, открывается и закрывается, крестик-анимация)
3. Проверка формы: имя, email, сообщение, сообщения об ошибках и об успехе
